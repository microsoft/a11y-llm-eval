Modal Dialog Title

This is an example of a simple modal dialog component.

It's hidden by default and triggered by a button with the .trigger class.

You can close it by:

  • Clicking the 'X' button.
  • Clicking the 'Cancel' button.
  • Pressing the 'Escape' key.
  • Clicking on the dimmed area outside the dialog box.
